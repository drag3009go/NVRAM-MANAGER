# NVRAM-MANAGER

**NVRAM-MANAGER** is a powerful software tool designed for viewing and editing UEFI NVRAM directly from within Windows. It also includes built-in features for restoring the Windows bootloader.

## ✨ Features

* **UEFI NVRAM Management:** View and edit NVRAM entries without leaving Windows.
* **Bootloader Restoration:** Easily restore your bootloader (currently available for **Windows 10 only**).
* **User-Friendly Interface:** Clear and intuitive design for both Windows 10 and Windows 11 users.

---

## 🚀 Getting Started

1. Clone or download this repository.
2. Ensure you have administrator privileges (required for NVRAM access).
3. Run the application from the `dist/` folder.
